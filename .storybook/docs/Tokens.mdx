# Design tokens

The library's design tokens (D0 spec, direction A "Evolved") are CSS custom
properties prefixed `--rq-`, shipped in `stylesheets/tokens.css` and included
in `stylesheets/index.css`. Light is the default; dark applies under
`data-theme="dark"`, or when the OS prefers dark and the root doesn't set
`data-theme="light"`. Use the **Theme** toolbar button to switch the stories.

The same values are Sass maps in the Sass API (`rq.$colors-light`,
`rq.$space`, …). These tables are generated from the compiled `tokens.css`.

## Colour

`brand` is for the logo mark and decoration only; on light backgrounds it is
below AA, so text uses `accent-text`.

## Text contrast

Every text token meets WCAG AA (4.5:1) on the backgrounds it's used on, in
both themes. The unit tests enforce this.

<ContrastTable />

## Type scale

Work Sans (variable, 100–900; load `stylesheets/fonts.css`). Spec roles: hero
`6xl`/300 (`5xl` on mobile), h2 `4xl`/400 (`3xl` on mobile), card titles
`2xl`/600, body `lg`–`2xl` at line height `body` (1.6), nav and buttons `md`,
eyebrow and meta `xs`, tags `2xs`.
